# Burglar alarm
You have a certain house that our rogue can enter.
Let's help Lyosha catch the swindler; to do this, an alarm system should be installed in the house.

It is better to install an alarm on the door, or in the interior of the house, so that we know that a swindler has entered.

When the swindler entered the house,
The alarm volume should begin to gradually increase to maximum. When the crook leaves, the volume should smoothly decrease to zero.
